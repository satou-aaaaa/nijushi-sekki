# 二十四節気

立春・啓蟄・夏至・霜降……1年を24に分けた季節のことば「二十四節気」の、名前・意味・季節・順番・日付を当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/nijushi-sekki/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「こよみ帳」があります。
- 問題は「どんなころ？」「読み方は？」「どの季節？」「次の節気は？」「この日に始まる節気は？」「太陽黄経が何度？」「節気と中気」「間の日数」、節分・彼岸・八十八夜などの雑節など。正解すると、24の節気を並べた「暦の輪」と「なぜ」と出典が出ます。
- 問題は453問（13種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

- [国立天文台 暦計算室「こよみ用語解説 二十四節気」](https://eco.mtk.nao.ac.jp/koyomi/faq/24sekki.html)：節気は太陽黄経で決める・節気と中気が交互に来る、各節気の意味、雑節の説明
- [国立天文台「暦要項 令和8年（2026）」](https://eco.mtk.nao.ac.jp/koyomi/yoko/2026/rekiyou262.html)・[令和9年（2027）](https://eco.mtk.nao.ac.jp/koyomi/yoko/2027/rekiyou272.html)：各節気の日時（中央標準時）と太陽黄経
- [国立国会図書館「日本の暦」二十四節気](https://www.ndl.go.jp/koyomi/chapter3/s7.html)：季節の分け方（春は立春〜穀雨など）

日付は年によって1日ほど変わります。このゲームの日付は2026年・2027年の暦要項のものです。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
